# AsiaKoz · Реклама

Панель рекламы клиники «Азиякөз»: расход Meta, чаты с кодом WhatsApp-шаблона (Wazzup) и записи на приём (amoCRM) по филиалам и объявлениям.

- Сайт: https://ads.asiakoz.com (GitHub Pages)
- Данные: Supabase-проект AsiaKoz Analytics, функции `ad_panel`, `ad_panel_set_stage`, `ad_panel_sync_meta` (доступ — раздел «Маркетинг»).
- Вход: те же email и пароль, что в AsiaKoz Analytics.
- В коде только публикуемый (publishable) ключ Supabase; все данные закрыты проверкой роли на сервере.
